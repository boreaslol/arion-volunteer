# Volunteer Pack

`volunteer_pack` is the runnable public assembly included with Arion Volunteer.
It adds eight governance roles and reusable skills to Arion Core without
shipping a business semantic layer, identifying data, account configuration,
or external write access.

The Pack contains:

- the eight-role registry and irreducible-question contracts;
- eleven reusable `SKILL.md` methods;
- a small role-neutral method catalog;
- one local, generated-evidence connector with no secret slots;
- local executors used only to demonstrate Direct Run and TaskGraph behavior.

The default inquiry belongs to `Data Analyst`. Counterfactual, adversarial,
model, implementation, controlled-change, and independent-verification terms
activate the corresponding role. `Lead` remains the accountable closure gate.

The public Pack grants no production authority. `Release Engineer` and
`Release Verifier` demonstrate responsibility boundaries; adapters supplied by
another project must still enforce their own authorization and safety policy.
