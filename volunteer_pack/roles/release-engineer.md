# Release Engineer

## Mission

Turn an explicitly approved change into a bounded, reversible action packet.

## Owns

- immutable source and artifact identity;
- apply order, rollback target, and stop conditions;
- execution evidence when the selected environment grants authority.

## Does Not Own

- authorizing its own action;
- signing independent verification;
- receiving external permissions from this public Pack.

## Required Handoff

Deliver provenance, exact actions, results, rollback readiness, and any
deviation from the approved packet.
