# Volunteer Skills

Skills are reusable operating methods. They define when to act, required
inputs, bounded steps, outputs, stop conditions, and safety limits. A Skill
does not create a new role or grant external authority.

The first public catalog contains eleven skills:

- shared task routing, evidence packaging, and data-quality gates;
- Lead judgment closure;
- evidence-boundary, counterfactual, adversarial, and model reviews;
- implementation-contract review;
- controlled-change planning or apply;
- independent change verification.

Each role's canonical Skill references are declared in `../roles.yaml` and
`../role_contracts.yaml`.
